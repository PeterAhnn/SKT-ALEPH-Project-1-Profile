# 구현 검토와 수정 기록

작업 범위: 현재 패스키 구현의 정확성과 공식 47개 기준의 대응 관계를 별도 담당자가 읽기 전용으로 검토했습니다. 광범위한 보안 감사나 운영 환경 판정을 뜻하지 않습니다.

## 최초 등록 중 로그아웃·취소 경합

- 수정 전: 등록 질문을 소비한 직후 로그아웃 또는 취소가 완료되어도 등록 검증이 200으로 완료되고 계정·패스키·세션이 생성되는 것을 인메모리 HTTP 시험으로 재현했습니다.
- 수정: 최종 등록 저장 직전에 폐기된 flow와 해당 flow·challenge의 취소 표지를 확인합니다. 소비 시점에도 검사합니다.
- 재검증: 같은 브라우저의 로그아웃·취소는 401이며 계정·패스키·세션은 모두 0개입니다. 다른 브라우저의 로그아웃·취소에는 영향을 받지 않고, 취소 후 새 등록은 정상 완료합니다.
- 증거: tests/registration.test.mjs의 경합 회귀시험 6개입니다. 독립 검토 담당자가 해당 6개를 다시 실행해 모두 통과했습니다.

## 자료 조회 실패를 성공 안내로 덮어쓰던 문제

- 수정 전: 등록·로그인은 성공했지만 `/api/private/items`를 의도적으로 503으로 만들면 비공개 자료가 보이지 않아도 공간을 열었다는 안내를 표시했습니다.
- 수정: 화면 갱신 함수가 성공 여부를 반환하고, 각 처리 함수가 실패하면 성공 안내를 쓰지 않습니다.
- 재검증: 등록 직후와 로그인 직후에 자료 조회를 각각 503으로 바꾼 브라우저 시험에서 오류 문구가 유지되고 비공개 내용은 숨겨졌습니다.
- 증거 출처: 독립 검토 담당자의 파일 변경 없는 Chromium 가상 인증기 재현 결과입니다. 이 문서는 실제 운영 장애 기록이 아닙니다.
